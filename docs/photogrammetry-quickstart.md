# Itemize · จากรูปถ่ายไป Blender บน Windows

Itemize ใช้ Python เตรียมรูป ใช้ COLMAP คำนวณรูปทรงจากมุมที่ถ่ายจริง และให้ Blender แปลงพื้นผิวเป็น `.glb` หลังเปิดไฟล์ใน Blender แล้วสามารถปรับรูปทรงและบันทึกเป็น `.blend` เพื่อทำงานต่อได้

## 1. ถ่ายรูปวัตถุหนึ่งชิ้น

1. เริ่มจากวัตถุผิวด้านที่มีขอบและลายชัด เช่น กล่องกระดาษพิมพ์ลาย ถ้าจะลองรถ Mini 4WD ให้ใช้แสงนุ่มจากโคมไฟหรือหน้าต่าง และคาดว่าชิ้นส่วนมันวาวหรือบางอาจมีผิวขาด
2. วางวัตถุให้อยู่นิ่ง แล้วเดินถือมือถือถ่ายรอบวัตถุสองรอบ รอบแรกอยู่ประมาณระดับตัววัตถุ รอบที่สองสูงขึ้นเพื่อให้เห็นด้านบน ถ่ายประมาณ 20–30 รูปต่อรอบ ให้แต่ละภาพเห็นรายละเอียดซ้ำกับภาพก่อนหน้า ใช้เลนส์เดิมและถ่ายให้เห็นวัตถุครบทั้งชิ้น
3. คัดลอกภาพ JPG/PNG ลงในโฟลเดอร์เดียว เช่น `data/01_raw/normal/object_01` ถ้าโทรศัพท์ใช้ HEIC ให้ตั้งให้บันทึก JPEG หรือส่งออกรูปเป็น JPEG ก่อน

ขาตั้งกล้องใช้ช่วยให้ภาพนิ่งได้โดยย้ายขาตั้งเดินรอบวัตถุ การหมุนวัตถุหน้ากล้องคงที่ควรทดลองแยก เพราะ COLMAP อาจจับคู่จุดบนฉากหลังที่อยู่นิ่งแทนจุดบนวัตถุ เมื่อมีพื้นโต๊ะติดมากับโมเดล สามารถตัดออกใน Blender ได้

## 2. เตรียมโปรแกรม

เปิด PowerShell ในโฟลเดอร์ Itemize แล้วใช้ Python ที่ติดตั้งไว้ ถ้าเครื่องนี้มีสภาพแวดล้อมเดิมให้ใช้ `.\.venv-gpu\Scripts\python.exe` แทน `python` ในคำสั่งต่อไปนี้ ถ้าต้องติดตั้งไลบรารีให้ใช้คำสั่งนี้

```powershell
python -m pip install -r requirements/photogrammetry.txt
python -m src.photogrammetry --help
```

การเตรียมภาพใช้ Python อย่างเดียว สำหรับการสร้างโมเดลเต็มรูปแบบ ให้เตรียม COLMAP 4.1.x รุ่น Windows ที่รองรับ CUDA และ Blender 4.5 หรือใหม่กว่า แตกไฟล์รุ่นพกพาออกทั้งชุดและหาพาธไปยัง `colmap.exe` กับ `blender.exe` โดยเก็บไฟล์ DLL ที่มาด้วยไว้ในโครงเดิม

- [COLMAP Releases](https://github.com/colmap/colmap/releases)
- [คู่มือติดตั้ง COLMAP](https://colmap.github.io/install.html)
- [ดาวน์โหลด Blender](https://www.blender.org/download/)

ตรวจว่าเครื่องเปิดเครื่องมือได้ เปลี่ยนพาธทั้งสองให้ตรงกับตำแหน่งบนเครื่อง

```powershell
$colmap = 'D:\Tools\COLMAP\bin\colmap.exe'
$blender = 'D:\Tools\Blender\blender.exe'
& $colmap -h
& $blender --version
nvidia-smi
```

## 3. ลองวัดความคมก่อนสร้างโมเดล

```powershell
$photos = 'data/01_raw/normal/object_01'
python -m src.photogrammetry --images $photos --output 'results/object_01-preview' --prepare-only
```

เปิด `results/object_01-preview/report.json` ดูคะแนน `sharpness` ของแต่ละภาพ ค่าสูงมักหมายถึงรายละเอียดขอบมากขึ้นเมื่อเทียบภาพของวัตถุเดียวกัน ให้ลองเทียบภาพที่มองแล้วชัดกับภาพที่มองแล้วเบลอ แล้วเลือกเกณฑ์สำหรับชุดของตัวเอง ค่าเริ่มต้นคือ 30 ทุกคำสั่งต้องใช้โฟลเดอร์ผลลัพธ์ชื่อใหม่เพื่อให้เปรียบเทียบกับรอบก่อนหน้าได้

## 4. สร้างและเปิดโมเดล

```powershell
python -m src.photogrammetry --images $photos --output 'results/object_01-baseline' --colmap $colmap --blender $blender
```

ถ้ารันครบ จะได้ `results/object_01-baseline/model.glb` เปิด Blender แล้วเลือก **File → Import → glTF 2.0 (.glb/.gltf)** เลือกไฟล์ คลิกเลือกโมเดลแล้วกด **Tab** เข้า Edit Mode ลองเลือกจุดยอดหนึ่งจุดและกด **G** เพื่อขยับ และกด **Esc** เพื่อยกเลิกการขยับ ถ้าต้องตัดพื้นโต๊ะ ให้เลือกหน้าที่เป็นพื้นโต๊ะใน Edit Mode แล้วลบส่วนที่เลือก

ระหว่างรอถ่ายรูป สามารถตรวจว่าระบบรันครบด้วยโฟลเดอร์ภาพจากชุดตัวอย่างที่ COLMAP เผยแพร่ เก็บผลรอบนี้ไว้สำหรับตรวจเครื่องมือ และใช้รูปที่ถ่ายเองสำหรับประเมินรูปทรงของวัตถุในรายงานวิชา [ชุดข้อมูลตัวอย่างของ COLMAP](https://colmap.github.io/datasets.html)

ถ้ารันไม่ครบ ให้เปิด `report.json` ดู `failed_stage` และเปิดไฟล์ชื่อตรงกันใน `logs/` หากไปถึงขั้นสร้างกลุ่มจุดแล้ว รายงานจะแสดงพาธของกลุ่มจุดที่เก็บไว้ เมื่อ GPU มีหน่วยความจำไม่พอ ให้ลองรอบใหม่ด้วย `--max-image-size 1200` ค่าเริ่มต้นคือ 1600 พิกเซล ตัวเลือก `--cpu-features` เปลี่ยนเฉพาะการหาจุดเด่นและจับคู่ไปใช้ CPU ขั้นสร้างความลึกของ COLMAP ยังต้องใช้ CUDA

## 5. ทำการทดลองสำหรับวิชา

รันภาพชุดเดิมสามรอบด้วยเกณฑ์ความคมและค่าของ COLMAP ชุดเดียวกัน ใช้ `--mode baseline` สำหรับภาพอ้างอิง จากนั้นใช้ `--mode filter` และ `--mode filter-clahe` ในโฟลเดอร์ผลลัพธ์ชื่อใหม่ โหมดหลังใช้ภาพชุดเดียวกับ `filter` แล้วปรับความเปรียบต่างเฉพาะบริเวณในช่องความสว่างด้วย CLAHE

| ค่าที่บันทึก | ดูจาก |
|---|---|
| ภาพต้นทางและภาพที่ส่งเข้า COLMAP | `counts.original`, `counts.accepted` |
| ภาพที่คำนวณตำแหน่งกล้องได้ | `counts.registered` คิดเป็นสัดส่วนเทียบทั้งภาพต้นทางและภาพที่ส่งเข้า |
| เวลารวมและขั้นที่ผิดพลาด | `elapsed_seconds`, `failed_stage` |
| ผิวที่สร้างได้และผิวที่ขาด | ภาพหน้าจอจากมุมเดียวกันหลังจัดแนวโมเดลใน Blender |

## 6. ลองคลิปสั้นหลังทดสอบภาพถ่าย

ถ่าย MP4 โดยเดินรอบวัตถุที่ตั้งอยู่กับที่ เคลื่อนกล้องช้า ๆ ให้เห็นด้านบนและมุมรอบวัตถุ Itemize อ่านเฟรมตามช่วงเวลาและคัดเฟรมเบลอกับเฟรมที่คล้ายเฟรมล่าสุดที่เลือก ดูเวลาและผลการคัดใน `frames` ภายใน `report.json`

```powershell
$clip = 'data/01_raw/object_01.mp4'
python -m src.photogrammetry --video $clip --video-interval 0.5 --output 'results/object_01-video-preview' --prepare-only
python -m src.photogrammetry --video $clip --video-interval 0.5 --output 'results/object_01-video' --colmap $colmap --blender $blender
```
