# Itemize Photogrammetry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** สร้างไฟล์ `.glb` ที่แก้ไขใน Blender ได้จากชุดภาพถ่ายจริง และเพิ่มการรับวิดีโอหลังเส้นทางภาพนิ่งผ่านการทดสอบ

**Architecture:** ใช้คำสั่ง `python -m src.photogrammetry` เป็นทางเข้าบน Windows ให้ Python เตรียมภาพและจัดการผลรายรอบ จากนั้นเรียก COLMAP สร้างผิว `.ply` และเรียก Blender แบบเบื้องหลังเพื่อส่งออก `.glb` โหมดวิดีโอจะส่งเฟรมเข้ากระบวนการเดียวกับภาพถ่าย

**Tech Stack:** Python, Pillow, OpenCV, NumPy, COLMAP CLI, Blender CLI, pytest

**Spec:** [แบบระบบที่อนุมัติ](../specs/2026-11-26-itemize-photogrammetry-design.md)

## Global Constraints

- รุ่นภาพนิ่งรับโฟลเดอร์ JPG/PNG หนึ่งวัตถุ รองรับ `.jpeg` ด้วย และใช้แนวทางถ่ายประมาณ 40–60 ภาพเป็นจุดเริ่มต้น
- เก็บต้นฉบับไว้ที่เดิม สร้างโฟลเดอร์ผลลัพธ์ใหม่ต่อรอบ บันทึกค่าที่ใช้ รุ่นเครื่องมือ จำนวนภาพ ระยะเวลา และสถานะรายขั้น
- เดโมภาพถ่ายและวิดีโอตัดพื้นโต๊ะใน Blender ด้วยมือได้ ขอบเขตเน้นรูปทรงที่แก้ได้และยอมรับว่าบางผิวอาจขาดหาย
- ตรวจความพร้อมด้วยโปรแกรมที่รันได้จริง การทดสอบกับตัวจำลองตรวจได้เฉพาะการประสานคำสั่งและการจัดการผล
- เป้าหมายเปิดโมเดลภาพนิ่งในสัปดาห์ที่ 3 เปรียบเทียบการเตรียมภาพในสัปดาห์ที่ 5–6 และเพิ่มวิดีโอในสัปดาห์ที่ 7–9
- การสร้าง Git commit ขึ้นกับสิทธิ์เขียน `.git` ขณะนี้ไฟล์งานจะอยู่ในโฟลเดอร์โปรเจกต์

## Review Focus

- ภาพเสียหรือมี EXIF หมุนภาพต้องเห็นผลแยกรายไฟล์ในรายงาน และภาพที่ใช้ต้องตั้งตรง (งาน 2)
- ชื่อไฟล์หรือพาธมีช่องว่างต้องส่งถึงโปรแกรมภายนอกครบหนึ่งอาร์กิวเมนต์ (งาน 3)
- COLMAP อาจสร้างหลายกลุ่ม เลือกกลุ่มที่ใช้ภาพมากที่สุดและบันทึกกลุ่มที่เลือก (งาน 3)
- หากสร้างกลุ่มจุดได้แล้วแต่สร้างผิวล้มเหลว ให้เก็บจุดและบันทึกขั้นที่ล้มเหลว (งาน 3)
- Blender อาจส่งคืนผลสำเร็จแต่ไฟล์ไม่มีผิวสามเหลี่ยมที่ใช้แก้ไขได้ ตรวจทั้งตอนนำเข้า PLY และตอนนำเข้า GLB กลับ (งาน 4)

## 1. ตรวจเครื่องมือและลองกับข้อมูลจริง

**ไฟล์** `docs/photogrammetry-quickstart.md` สำหรับขั้นติดตั้ง ถ่ายภาพ รัน และเปิดผล

- [ ] ตรวจรุ่นจริงด้วย `python --version`, `nvidia-smi`, `colmap -h` และ `blender --version` ถ้าเครื่องมือภายนอกไม่อยู่ใน `PATH` ให้รองรับพาธเต็ม เก็บสำเนาโปรแกรมแบบพกพาในพื้นที่ที่เขียนได้เมื่อหาโปรแกรมเดิมไม่พบ
- [ ] ทดลอง COLMAP กับชุดภาพตัวอย่างที่เผยแพร่พร้อมสิทธิ์ใช้งาน แล้วบันทึกผลถึงขั้นสร้างความลึกบน GPU และสร้าง mesh แยกการตรวจเครื่องมือออกจากการตรวจคุณภาพภาพถ่ายของผู้ใช้
- [ ] ลงคู่มือถ่ายด้วยมือถือรอบวัตถุคงที่สองระดับ มีภาพซ้อนกันและแสงสม่ำเสมอ แนะนำวัตถุผิวด้านพิมพ์ลายสำหรับชุดแรก หากใช้แท่นหมุนกับกล้องคงที่ ให้ใช้เป็นการทดลองแยก เพราะฉากหลังคงที่อาจถูกจับคู่เป็นวัตถุ และการตัดฉากหลังอัตโนมัติอยู่นอกขอบเขตรุ่นนี้

## 2. เตรียมภาพและบันทึกคะแนน

**ไฟล์** `src/photogrammetry/images.py`, `requirements/photogrammetry.txt`, `tests/test_photogrammetry_images.py`

**อินเทอร์เฟซ** `prepare_images(source: Path, destination: Path, *, mode: str, blur_threshold: float) -> list[ImageRecord]` คืนรายการที่มี `source`, `prepared`, `sharpness`, `status`, `detail` โหมดคือ `baseline`, `filter`, `filter-clahe`

- [ ] เขียนชุดทดสอบให้ภาพขอบชัดได้คะแนนสูงกว่าภาพที่ทำให้เบลอ ภาพเสียมีสถานะ `unreadable` ภาพ EXIF orientation 6 หมุนถูกทาง และไฟล์ต้นฉบับคงเดิมเมื่อรันทุกโหมด
- [ ] รัน `python -m pytest tests/test_photogrammetry_images.py -q` ให้เห็นข้อผิดพลาดจากส่วนที่ยังไม่มี ก่อนลงมือเขียน
- [ ] ใช้ Pillow หมุนภาพตาม EXIF แล้วจัดรูปแบบและตั้งชื่อผลอย่างเดียวกันทุกโหมด ใช้ OpenCV คำนวณ Laplacian variance บนภาพเทาที่มีเกณฑ์ปรับขนาดเท่ากัน เปลี่ยน threshold ได้ ใช้ CLAHE บนช่อง L ของภาพ Lab เฉพาะ `filter-clahe`
- [ ] รันทดสอบเดิมให้ผ่าน และยืนยันว่าชุดภาพที่เหลือใน `filter` กับ `filter-clahe` เป็นชุดเดียวกัน

## 3. สร้างผิวด้วย COLMAP

**ไฟล์** `src/photogrammetry/reconstruction.py`, `tests/test_photogrammetry_reconstruction.py`

**อินเทอร์เฟซ** `reconstruct(colmap: Path, images: Path, workspace: Path, *, max_image_size: int, use_gpu: bool) -> ReconstructionResult` คืน `registered_images`, `sparse_cloud`, `dense_cloud` และ `mesh` เมื่อถึงขั้นที่เกี่ยวข้อง และเก็บเหตุการณ์รายขั้นในไฟล์ใต้ `workspace` แม้ขั้นถัดไปล้มเหลว

- [ ] เขียนตัวจำลองโปรแกรมภายนอกที่บันทึกอาร์กิวเมนต์ สร้างโมเดลสองกลุ่ม และคืน error ตอนสร้างผิว ทดสอบพาธมีช่องว่าง การเลือกกลุ่มที่มีภาพมากกว่า และการเก็บกลุ่มจุดกับชื่อขั้นที่ล้มเหลว
- [ ] รัน `python -m pytest tests/test_photogrammetry_reconstruction.py -q` ให้ทดสอบส่วนที่ยังไม่มีแสดงผลล้มเหลว
- [ ] เรียงขั้น `feature_extractor`, `exhaustive_matcher`, `mapper`, เลือกกลุ่มจากจำนวนภาพใน `model_analyzer`, ส่งออกกลุ่มจุด sparse, `image_undistorter`, `patch_match_stereo`, `stereo_fusion`, `poisson_mesher` ตรวจไฟล์ผลแต่ละขั้นก่อนเดินต่อ เก็บ stdout และ stderr ของทุกคำสั่ง ใช้รายการอาร์กิวเมนต์และรองรับ executable จริงบน Windows
- [ ] รันทดสอบเดิมให้ผ่าน ลองบน GPU จริงด้วยการจำกัดขนาดภาพเริ่มต้นที่ 1600 พิกเซล และบันทึกการตั้งค่าที่รันผ่าน

## 4. ส่งออก GLB และเชื่อมเป็นคำสั่งเดียว

**ไฟล์** `src/photogrammetry/__main__.py`, `src/photogrammetry/export_glb.py`, `tests/test_photogrammetry_cli.py`, `docs/photogrammetry-quickstart.md`

**อินเทอร์เฟซ** `python -m src.photogrammetry --images <folder> --output <run-folder>`  รองรับ `--mode`, `--blur-threshold`, `--colmap`, `--blender`, `--max-image-size` และ `--prepare-only` สร้าง `report.json` และ `model.glb` เมื่อรันครบ

- [ ] เขียนชุดทดสอบทางเข้าจริงด้วยตัวจำลอง COLMAP และ Blender ทดสอบโหมดเตรียมภาพอย่างเดียว โฟลเดอร์ผลลัพธ์ที่มีอยู่แล้ว ไฟล์ส่งออกเสียหรือหาย และสถานะรายงานหลังขั้นกลางล้มเหลว
- [ ] รัน `python -m pytest tests/test_photogrammetry_cli.py -q` ให้เห็นข้อผิดพลาดจากส่วนที่ยังไม่มี
- [ ] ให้คำสั่งตรวจเครื่องมือก่อนเริ่มงานหนัก สร้างโฟลเดอร์ผลลัพธ์ใหม่ เชื่อมการเตรียมภาพ การสร้างผิว และ Blender แบบ background ให้สคริปต์ Blender ตรวจว่า PLY มี faces ส่งออก GLB และตรวจว่านำไฟล์กลับเข้า Blender แล้วมี mesh บันทึก `report.json` ทั้งกรณีสำเร็จและล้มเหลว
- [ ] รัน `python -m pytest -q` และรันคำสั่งกับรูปที่ผู้ใช้ถ่ายเอง เปิด GLB ใน Blender ตรวจด้านหน้า หลัง และข้าง ขยับจุดยอดหนึ่งจุด และบันทึกมุมที่ผิวขาด

## ผลตรวจรอบแรก

- เตรียมภาพและวิดีโอได้ด้วย Python เดิมของโปรเจกต์ การทดสอบครอบคลุมภาพเสีย ภาพหมุนตาม EXIF การคัดภาพเบลอ การอ่านเวลาจากคลิป และการเก็บผลเมื่อขั้นสร้างผิวหรือส่งออกล้มเหลว
- คำสั่งจริงในโหมดเตรียมภาพใช้ภาพทดสอบสามไฟล์ โหมดอ้างอิงรับสองภาพ ส่วนโหมดคัดเบลอและโหมดคัดเบลอพร้อมปรับแสงรับอย่างละหนึ่งภาพ
- ตรวจพบ RTX 3060 Laptop GPU ขนาด 6 GB ยังไม่พบโปรแกรม COLMAP และ Blender ใน `PATH` หรือโฟลเดอร์ติดตั้งปกติ เทอร์มินัลแก้ชื่อโดเมนดาวน์โหลดไม่สำเร็จ และ `data/01_raw` ยังไม่มีรูปถ่ายหรือคลิปจริง การตรวจ CUDA การเปิด GLB ใน Blender และผลทดลองของวัตถุจริงยังรอข้อมูลและเครื่องมือทั้งสอง
