# แบบระบบ Itemize สำหรับวิชา Digital Image Processing

26 พฤศจิกายน 2569 · ฉบับเสนออนุมัติ

## เป้าหมาย

ใช้โทรศัพท์ถ่ายวัตถุจริงรอบด้าน แล้วให้ Itemize สร้างไฟล์ `.glb` ที่นำเข้า Blender เพื่อแก้รูปทรงต่อได้ ผู้ทำโปรเจกต์จะได้เรียนรู้การเตรียมภาพ การวัดความคมชัด และการออกแบบการทดลอง โดยใช้ COLMAP คำนวณรูปทรงสามมิติจากภาพหลายมุม

รุ่นแรกเริ่มจากโฟลเดอร์รูปถ่ายหนึ่งวัตถุด้วยคำสั่งเดียวผ่าน PowerShell เมื่อเส้นทางจากรูปถ่ายถึง Blender ผ่านเกณฑ์แล้ว จะเพิ่มการรับคลิป `.mp4` และคัดเฟรมเข้าเส้นทางเดียวกัน ขอบเขตสองเดือนเศษเน้นรูปทรงพื้นฐานที่แก้ไขได้ ส่วนสีพื้นผิวความละเอียดสูง สเกลจริงอัตโนมัติ และการเชื่อม Unity อยู่นอกขอบเขตงานสำหรับรายวิชารอบนี้

## แนวทางที่เลือก

| แนวทาง | ข้อแลกเปลี่ยน |
|---|---|
| **Photogrammetry ด้วย COLMAP — เลือกใช้** | ใช้ภาพจริงหลายมุม อาศัยรายละเอียดที่มองเห็นซ้ำเพื่อประมาณตำแหน่งกล้องและสร้างพื้นผิว เหมาะกับโจทย์ที่ต้องการรูปทรงอิงวัตถุจริงและเปรียบเทียบผลของการเตรียมภาพ ต้องถ่ายภาพให้มีมุมซ้อนทับและใช้ GPU สำหรับขั้นสร้างความลึกแบบหนาแน่นของ COLMAP |
| InstantMesh จากภาพเดียว | ใช้ภาพจริงน้อยกว่า โดยสร้างภาพมุมอื่นขึ้นมาเป็นส่วนหนึ่งของกระบวนการ เหมาะกับการสร้างรูปทรงตั้งต้นจากภาพเดียว และประเมินความตรงกับวัตถุจริงรอบด้านได้ยากกว่า |

แผน Itemize เดิมใช้ภาพ 6–8 มุมสำหรับอีกวิธีหนึ่ง แผนถ่ายภาพ Photogrammetry จะเริ่มด้วยภาพประมาณ 40–60 ภาพ โดยปรับจำนวนตามผลทดลอง และใช้โครงโฟลเดอร์ข้อมูลของโปรเจกต์เดิม

## การถ่ายภาพและการทำงานของระบบ

1. **ถ่ายภาพ** — วางวัตถุผิวด้านที่มีลายชัดให้อยู่นิ่ง เช่น กล่องกระดาษพิมพ์ลาย วางบนโต๊ะที่แสงสม่ำเสมอ เดินถือโทรศัพท์รอบวัตถุสองระดับ ถ่ายให้ภาพติดกันเห็นรายละเอียดซ้ำ เก็บด้านบนและมุมเฉียงที่เข้าถึงได้ พื้นผิวที่ถูกโต๊ะบังจะอยู่นอกขอบเขตการสแกนครั้งแรก ตั้งต้นด้วย JPG/PNG และตรวจการหมุนภาพจากข้อมูล EXIF ก่อนประมวลผล
2. **เตรียมภาพด้วย Python และ OpenCV** — ตรวจไฟล์และรายงานไฟล์ที่อ่านไม่ได้ วัดความคมด้วยค่าความแปรปรวนของ Laplacian บนภาพเทาที่ปรับขนาดตามเกณฑ์เดียวกัน รายงานคะแนนรายภาพและปรับเกณฑ์คัดภาพได้ ให้ผู้ใช้เห็นภาพที่ถูกตัดและตรวจว่ามุมสำคัญยังครบ สำหรับโหมดปรับแสง ให้ใช้ CLAHE บนช่องความสว่างโดยคงขนาดภาพและทดสอบแยกจากการคัดภาพเบลอ
3. **สร้างรูปทรงด้วย COLMAP** — จับคู่จุดเด่นระหว่างภาพ คำนวณตำแหน่งกล้องและสร้างกลุ่มจุดสามมิติเบื้องต้น (Structure from Motion) จากนั้นคำนวณความลึกจากภาพหลายมุม (Multi-View Stereo) รวมเป็นกลุ่มจุดหนาแน่น แล้วสร้างตาข่ายพื้นผิวสามเหลี่ยม (mesh) เป็นไฟล์ `.ply`
4. **เตรียมไฟล์สำหรับ Blender** — ทดลองนำเข้า `.ply` และตรวจพื้นผิวก่อนเขียนสคริปต์ส่งออก `.glb` ผ่าน Blender ทั้งเดโมภาพนิ่งและวิดีโออนุญาตให้มีพื้นโต๊ะติดมากับไฟล์ที่ระบบส่งออก ผู้ใช้สามารถตัดส่วนเกินใน Blender ตามขั้นตอนในคู่มือและบันทึกไฟล์งาน `.blend` ของตัวเองได้ การแยกวัตถุออกจากฉากอัตโนมัติอยู่นอกขอบเขตรอบนี้
5. **เพิ่มวิดีโอหลังรุ่นภาพถ่ายใช้งานได้** — อ่านคลิปสั้นและดึงเฟรมตามช่วงเวลา กรองเฟรมเบลอและเฟรมที่ใกล้เคียงกันมาก เก็บเวลาต้นทางของเฟรม ให้ผู้ใช้ตรวจว่าภาพที่เลือกเห็นวัตถุรอบด้าน ก่อนส่งเข้าเส้นทางเดิม

ทุกรอบเก็บภาพต้นฉบับไว้ที่เดิม พร้อมบันทึกค่าที่ใช้ จำนวนภาพในแต่ละขั้น รุ่นเครื่องมือ และข้อความเมื่อเกิดข้อผิดพลาด ผลแต่ละรอบอยู่คนละโฟลเดอร์เพื่อให้เปิดเปรียบเทียบย้อนหลังได้ หาก COLMAP ไปได้ถึงกลุ่มจุดแต่ยังสร้างพื้นผิวไม่ได้ ให้แสดงขั้นที่หยุดและส่งมอบกลุ่มจุดเป็นผลระหว่างทาง

## เกณฑ์ผ่านและการทดลอง

- **เกณฑ์รุ่นภาพถ่าย** — ใช้ภาพที่ถ่ายเองสร้าง `.glb` อย่างน้อยหนึ่งชิ้น นำเข้า Blender แล้วเห็นผิวตาข่ายของวัตถุจากด้านหน้า ด้านหลัง และด้านข้าง เลือกและขยับจุดยอดใน Edit Mode ได้ เก็บภาพหน้าจอเทียบกับภาพถ่ายและบันทึกจุดที่ผิวขาดหรือมีพื้นโต๊ะติดมา
- **เปรียบเทียบการประมวลผลภาพ** — ใช้ภาพต้นทางชุดเดียวกันในสามรอบ ได้แก่ ภาพอ้างอิงที่ผ่านเฉพาะการเตรียมไฟล์ร่วมกัน ภาพที่คัดเบลอ และภาพที่คัดเบลอแล้วปรับแสง ใช้การตั้งค่า COLMAP ชุดเดียวกัน ตรวจให้รอบที่สองและสามใช้รูปชุดเดียวกัน วัดจำนวนภาพที่ COLMAP คำนวณตำแหน่งกล้องได้เทียบทั้งกับจำนวนที่ส่งเข้าและกับจำนวนภาพต้นฉบับ วัดเวลาที่ใช้ และเปรียบเทียบพื้นผิวจากมุมเดียวกันหลังจัดแนวโมเดล ผลทดลองใช้ได้แม้การปรับแสงจะทำให้ผลแย่ลง
- **เกณฑ์วิดีโอ** — ใช้คลิปที่ถ่ายเองหนึ่งคลิป สร้างผล `.glb` ที่เปิดได้ใน Blender พร้อมรายการเฟรมที่เลือก ให้แสดงหลักฐานผลแยกจากการทดลองภาพนิ่ง

## หลักฐานความคืบหน้า

| ช่วงโดยประมาณ | สิ่งที่ใช้แสดงให้อาจารย์ดู |
|---|---|
| สัปดาห์ 1–2 | ตรวจว่า COLMAP และ Blender รันบน Windows ได้ ทดสอบขั้นสร้างความลึกกับ GPU แล้วนำชุดภาพที่ถ่ายเองและตัวอย่างคะแนนความคมมาแสดง |
| สัปดาห์ 3–4 | เป้าหมายเปิดโมเดลชิ้นแรกในสัปดาห์ที่ 3 และสาธิตแก้จุดยอดใน Blender พร้อมบันทึกปัญหาผิวขาด พื้นโต๊ะ และเวลารัน |
| สัปดาห์ 5–6 | ตารางผลทดลองสามรอบ รูปเทียบจากมุมเดียวกัน และขั้นตอนที่ทำซ้ำได้ |
| สัปดาห์ 7–9 | เดโมภาพนิ่งและคลิปสั้น สรุปข้อมูลนำเข้า ผลลัพธ์ ข้อจำกัด และคู่มือรันเพื่อใช้วันนำเสนอ |

เครื่องที่ตรวจพบมี NVIDIA GeForce RTX 3060 Laptop GPU พร้อมหน่วยความจำ 6 GB จึงจะทดสอบขั้นสร้างความลึกจริงในช่วงแรก เริ่มด้วยภาพลดขนาดระหว่างทดลอง และปรับตามเวลารันกับหน่วยความจำที่ใช้ หากขั้นนี้รันไม่ได้ ให้บันทึกข้อผิดพลาดและตรวจชุดติดตั้ง CUDA หรือทดสอบบนเครื่องที่รองรับก่อนตัดสินใจเปลี่ยนวิธีสร้างพื้นผิว
